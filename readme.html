SQLite Admin v1.0

A lightweight, self‑contained, single‑file SQLite database management tool.
All data stays on your server – no external dependencies, no cloud calls.

🔧 Requirements

  • PHP 7.0+ (7.4+ recommended)
  • SQLite3 extension (enabled by default in most PHP installations)
  • A web server (Apache, Nginx, or built‑in PHP server)

🚀 Installation (3 Steps)

  1. Upload all files (admin.php, install.php) to your web server (e.g., /var/www/html/sqlite-admin/).
  2. Run the installation wizard
    Open install.php in your browser:
    https://yourdomain.com/path/to/install.php
    • Set the database path (absolute or relative).
      Example: /var/www/html/data/my_database.sqlite
    • Choose an admin username and a strong password.
  3. Click “Install” – the script will:
    • Create the database file (if it doesn’t exist)
    • Generate a config.php file with your credentials (hashed)
    • Redirect you to admin.php

You can now log in with your username and password.

🔄 Upgrading to a New Version

Upgrading is safe and simple:

  1. Download the new admin.php (and optionally install.php) from the repository.
  2. Replace the old files on your server with the new ones.
  3. That’s it – your config.php and all databases remain untouched.
    No need to re‑install or re‑enter credentials.

If you ever need to change the database path or admin password, you can:

  • Delete config.php and run install.php again (this will create a fresh config), or
  • Edit config.php manually (not recommended unless you know what you’re doing).

🔐 Security Notes

  • The config.php file contains your database path and hashed password – keep it secure.
  • The database file is stored on your server; ensure write permissions for the directory.
  • For production, consider placing config.php outside the web root (you can adjust the path in admin.php).
  • SSL (HTTPS) is strongly recommended to protect your password during login.

🧪 Development / Testing

Use the built‑in PHP server for quick testing:

php -S localhost:8000

Then visit http://localhost:8000/install.php.

🗂️ File Structure

.
├── admin.php          # Main admin interface
├── install.php        # One‑time installation wizard (safe to keep)
├── config.php         # Generated automatically (do not edit manually)
└── database.sqlite    # Your SQLite database (created during install)

🛠️ Features

  • Browse, edit, insert, delete rows
  • Table creation, renaming, dropping
  • Column management (add, rename – with undo)
  • Import / Export (CSV, JSON, SQL, full database)
  • Row count in sidebar
  • Filter and search
  • Bulk row deletion
  • Dark mode
  • Undo last 5 actions
  • Multiple database support
  • Responsive design
  • Resizable sidebar
