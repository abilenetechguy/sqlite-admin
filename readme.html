SQLite Admin v1.1.5

A lightweight, self-hosted PHP interface for browsing and maintaining SQLite databases.

Administrator tool: use HTTPS and restrict access with a VPN, IP allowlist, or an additional authentication layer.

Requirements

  • PHP 7.0–8.3 (PHP 8.x recommended)
  • PHP SQLite3 extension
  • Apache, Nginx, or another PHP-capable web server
  • Write access to the database directory

Installation

  1. Upload the application files.
  2. Open install.php.
  3. Confirm the detected application folder.
  4. Choose the database location, then enter its filename or path within that location.
  5. Create the administrator login and sign in through admin.php.

The installer separates the application folder from the database location. Choose the SQLite Admin folder, its parent, the detected website root, or a custom absolute server path. Linux absolute paths must begin with /. When opening an existing database, leave the create-new-database checkbox unchecked so a typing error cannot silently create an empty database in the wrong folder.

Features

  • Browse tables and read-only views
  • Insert, edit, delete, search, filter, and paginate rows
  • Preserve SQL NULL values, empty strings, and BLOB fields
  • Import/export CSV, JSON, SQL, and full databases
  • Switch between database files
  • Schema tools and manual SQL
  • Dark mode, responsive layout, resizable sidebar, and five-action undo

Security

Keep config.php and database files inaccessible over HTTP. Apache deny files are included; Nginx and other servers require equivalent rules. Keep debug disabled in production.

Opening the application

Open admin.php directly, such as https://example.com/admin/admin.php. SQLite Admin does not set a directory index because site-level clean-URL rules can otherwise turn /admin/ into /admin/admin.
